# Κρεαταγορά Δίπλας Website

Απλό static website με `index.html`, `style.css`, `app.js` και εικόνες στο `public/images`.

## Τοπική εκτέλεση

Για απλό static preview:

```bash
python3 -m http.server 4173
```

Μετά άνοιξε:

```text
http://localhost:4173
```

## Κριτικές Google

Το section κριτικών περιέχει τρεις στατικές, ενδεικτικές κριτικές στο `index.html`. Το κουμπί `Δείτε τις κριτικές στο Google` οδηγεί στην καταχώριση της επιχείρησης στο Google Maps.
